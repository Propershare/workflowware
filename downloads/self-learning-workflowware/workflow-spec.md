# Workflow Spec

## Trigger

A learner wants to self-educate on a topic but needs structure to avoid shelf-help (consuming without applying).

## Goal

Run the SELF loop: Select a just-in-time topic, Extract insights through active study, Live it within 48 hours via the mirror test, Forge mastery through repetition.

## Inputs

- Current struggle or problem to solve
- Preferred learning formats (book, podcast, video, article)
- Available study time per day
- Sources to pull from for daily brief (optional)
- Concept to mirror-test (for Live phase)

## Finish line

The learner has:
1. A custom curriculum built from their current struggles
2. A daily study habit with one action item per session
3. Mirror test results showing comprehension gaps
4. A 48-hour action taken (or flagged as missed)
5. Mastery streak tracking over time

## Non-goals

- No paid course recommendations
- No community membership gates
- No email capture
- No content publishing without human approval
- No guarantees of mastery — the method works, but the work is yours
