# SELF Learning Workflowware

A free, Ma'at-governed workflow for self-education using the SELF framework (Select, Extract, Live, Forge). Extracted from Dan Martell's method. Stripped of the funnel. The method belongs to the people.

## What it does

Turns passive learning into governed action. The SELF loop ensures you study what matters, internalize it, apply it within 48 hours, and forge mastery over time.

## What it returns

- Custom learning curriculum based on your current struggles
- Daily study brief from your chosen sources
- Mirror test grading (explain a concept, get scored against source material)
- 48-hour action reminders
- Mastery streak tracking

## Device note

Phone users can run the prompts, receive daily briefs, and do mirror tests. Computer users can install the full Hermes cron jobs. No login. No community. No payment.

## AI agent instructions

1. Read `approval-rules.md` before suggesting action.
2. Interview the learner before building a curriculum.
3. Never recommend paid courses or communities unless the learner explicitly asks.
4. Grade mirror tests against source material only, not opinion.
5. Return plain-language summaries with next steps.
