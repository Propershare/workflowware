# Locked Homepage References

These files are the approved visual target for the Workflowware v2 homepage.

## Approved look

- ivory application canvas
- deep navy app shell
- restrained gold accents
- persistent left navigation rail
- top product navigation
- dense operational dashboard layout
- BUILD / VERIFY / DEPLOY hero
- Afrofuturist African profile illustration
- aligned Live Lab, System Health, Recent Activity, Quick Start, package, ecosystem, and community panels

## Reference files

- `dashboard-reference-desktop.png` — primary desktop visual target
- `dashboard-reference-agent-preview.png` — lightweight preview for small agents and quick repository inspection

## Rejected direction

Do not use the old lime marketing concepts as the homepage target. They are not part of the locked Workflowware v2 visual language.

## Agent rule

Before changing `index.html` or `assets/v2-polish.css`, inspect the reference PNGs and compare the proposed change against the approved shell, spacing, hierarchy, color balance, and panel placement.
