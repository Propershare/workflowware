The shift

Apps sold tools. Agents need the work packaged.

Prompts are ingredients. Agents are workers. Workflowware is the operating package.

If you remove the model, the package should still tell you how the job gets done.

Package anatomy

What every kit carries.

A Workflowware package is readable by people and agents — not a prompt dump.

  • Trust surface

    Explain what it does, who it’s for, and how it’s controlled.

  • Workflow spec

    Trigger, context, finish line, edge cases, success metrics.

  • Agent spec

    Role, tools, allowed actions, outputs, escalation.

  • Governance

    Approval rules, non-autonomous zones, audit expectations.

  • Evals

    Example inputs and expected behavior you can test.

  • Handoff

    Manifest + install path so the next operator can continue.
