What this is

A package for one job — not another chatbot.

Workflowware is a folder of instructions, rules, test cases, and handoff notes so a human and an AI agent can run the same job the same way. Swap the model if you want. The job definition stays.

MAAT is the governance layer. Workflowware is what you install. Doctrine: maatecosystem.com · llms.txt.
