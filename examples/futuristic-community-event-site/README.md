# Futuristic Community Event Website Workflowware

A stack-neutral Workflowware package for designing, generating, reviewing, and publishing a temporary client event landing page plus a reusable community hub.

This package is intentionally client-neutral. It contains no MAAT Ecosystem branding, links, emails, or runtime dependency.

## Outcome

The operator supplies the client's event facts and brand direction. The agent produces a responsive, reactive, accessible website with:

- a permanent community hub
- a removable event landing page
- futuristic AI-inspired visual treatment
- motion that respects reduced-motion preferences
- no invented event facts
- human approval before publication
- free-hosting guidance using GitHub Pages, Cloudflare Pages, Netlify, or Vercel subdomains

## Start

1. Read `workflow-spec.md`.
2. Fill in confirmed client facts.
3. Run the design agent under `agent-spec.md`.
4. Preview `index.html` locally.
5. Review against `approval-rules.md` and `eval-template.csv`.
6. Publish only after the client approves the exact copy, links, dates, location, and contact details.

## Package status

Prototype. The included `index.html` is a reactive design reference and trust surface, not a final client deployment.
