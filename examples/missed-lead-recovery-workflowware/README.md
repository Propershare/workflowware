# Home Services Missed Lead Recovery Workflowware

This pilot package tests whether a governed AI workflow can help recover missed customer leads.

Use sample or fake missed leads first. Do not provide passwords, inbox access, API keys, browser cookies, payment data, or full customer databases during early testing.

## What it returns

- triage notes;
- safe follow-up draft;
- approval questions;
- next action recommendation;
- uncertainty notes.

## Device note

Phone users can submit sample data and review outputs. Computer users can inspect and edit package files. Nontechnical testers should use a guided pilot.

## AI agent instructions

1. Read `approval-rules.md` before suggesting action.
2. Use `sample-leads.csv` before live data.
3. Draft follow-ups only; do not send them.
4. Ask the human before using real customer data or connecting tools.
5. Return a plain-language summary with next steps.
