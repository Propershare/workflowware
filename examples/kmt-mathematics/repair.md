# Kmt Mathematics - Repair

When a verification fails, the run stops (no silent progression) and surfaces
this repair procedure:

1. Re-derive the doubling table from scratch.
2. Re-select the rows and re-check the sum of factors equals the multiplier.
3. Re-sum the selected rows.
4. Re-verify by reverse division.
5. Only on a passing re-verification does the run continue to audit and handoff.
