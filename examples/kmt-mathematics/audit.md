# Kmt Mathematics - Audit

The whole-job audit checks that the run conformed to procedure and controls,
distinct from any single step's verification:

- Did the run produce a doubling table, a selection, and a result (evidence)?
- Was the verification performed by an independent method?
- Was a correction applied and re-verified if any check failed?
- Is the final result traceable to the recorded table and selection?

A task can be correct step-by-step yet fail the audit (e.g. missing provenance).
The audit fails the workflow unless all required evidence is present.
