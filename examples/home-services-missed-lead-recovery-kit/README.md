# Home Services Missed Lead Recovery Kit

This is the first concrete **Workflowware** package for the BlackLabRats / MAAT Agentic Workflow Distribution library.

## Promise

Turn missed calls, voicemails, web forms, and SMS leads into a governed follow-up workflow that qualifies the lead, captures missing details, books only under approved rules, and escalates uncertain cases to a human.

## Target buyers

- HVAC companies
- plumbers
- roofers
- pest-control companies
- landscapers
- electricians
- garage-door / appliance repair operators
- med-spa or appointment businesses with minor copy changes

- `index.html` — human-facing visual sales/demo artifact.
- `workflow-spec.md` — business workflow map.
- `agent-spec.md` — agent behavior spec.

- `agent-handoff.md` — future-agent operating instructions.

## Use this artifact when

A business owner says: “We miss calls/leads after hours or when busy, and those leads go to competitors.”

## Safety boundary

This kit starts as **draft-and-approve / triage / coordinator** workflowware. Do not sell it as an unattended receptionist without client-approved scripts, policies, tool access, evals, and escalation rules.
