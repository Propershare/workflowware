# Interim Brand Protection Plan for Workflowware™

> Non-legal strategy note. This is not legal advice and does not replace a trademark attorney.

## Situation

A federal trademark filing for `WORKFLOWWARE` costs money per class. Until there is budget to file, the strategy is to create a clear public usage trail, avoid overclaiming registration, and make the source/origin of the term visible.

## Use now

Use:

```text
Workflowware™
```

Do **not** use:

```text
Workflowware®
```

The `®` symbol should only be used after registration.

## Public positioning

Use this wording:

> Workflowware™ is software packaged as agent-operable workflows. Workflowware.org is maintained by BlackLabRats / propershare as a public category/spec home.

This does two things:

1. It timestamps the term as connected to the public site and maintainer.
2. It avoids claiming that nobody else can describe workflows or automation.

## What to publish before filing

1. `workflowware.org` landing page.
2. `propershare/workflowware` GitHub repo.
3. `SPEC.md` with the package structure.
4. `MANIFEST.schema.json`.
5. Example packages.
6. Origin note.
7. Tiers/pricing model.
8. This interim brand protection note.

## Low-cost evidence trail

After publishing, save evidence:

- first Git commit date;
- GitHub repo URL;
- workflowware.org live URL;
- Internet Archive snapshot;
- screenshots of the site;
- local MAAT artifact record;
- dated README/spec files;
- any public social posts announcing the term.

## Usage rules

### Good

```text
Workflowware™ package
Workflowware™ spec
Workflowware™ examples
Workflowware™ Installer Program
Workflowware.org is maintained by BlackLabRats / propershare
```

### Avoid

```text
Workflowware®
Officially registered Workflowware
Legally protected trademark
We invented all AI workflows
Only our runtime can run Workflowware
```

## Category vs brand balance

Because the goal is to spread the category, the language should stay open:

> Workflowware can be implemented with any agent/runtime stack. BlackLabRats uses MAAT Runtime as its governed memory and artifact foundation for professional installs.

Internally:

```text
MAAT Runtime = private/pro foundation
Workflowware.org = public category/spec surface
BlackLabRats = service/training brand
propershare/workflowware = public repo/spec
```

## Trademark filing later

When budget exists, consider filing:

```text
WORKFLOWWARE
```

Possible first class:

```text
Class 42 — software/platform/technical services
```

Possible stronger initial filing:

```text
Class 9 + Class 42
```

But do a clearance search before filing.
