# Archived: Homepage Finish task package (2026-08)

**Status: superseded. Not live. Do not execute.**

This was a multi-agent task package (`manifest.yaml`, `tasks.json`) scoped to
finish the Workflowware homepage to an "approved Afrofuturist dashboard
reference" — ivory/matte-black/deep-navy/gold palette, BUILD/VERIFY/DEPLOY
rail UI.

That direction is explicitly forbidden by [`AGENTS.md`](../../../AGENTS.md)'s
"Locked public site (LAW)" section: the live public homepage is the classic
lime + white marketing site, and restoring an ivory/gold Afrofuturist shell
requires Imhotep's explicit approval, which was not given.

## What happened

The task package's execution branch (`homepage-finish/head-dev-takeover`)
was deleted 2026-09-01 as part of a Maat audit remediation (see
[`../../../MAAT_AUDIT.md`](../../../MAAT_AUDIT.md)). `main` never adopted
the Afrofuturist direction — the lime marketing site was never replaced.

These files are kept here, not deleted outright, so the record of what was
attempted and why it was stopped survives — per the Maat self-reflection
principle, a repo should show its corrections, not just its current state.

## If you are an agent reading this

Do not treat `manifest.yaml` or `tasks.json` in this directory as a live
task queue. They describe a plan that was never authorized to ship. If a
similar homepage redesign is wanted in the future, it needs a fresh task
package and explicit sign-off recorded in `AGENTS.md`, not resumption of
this one.
